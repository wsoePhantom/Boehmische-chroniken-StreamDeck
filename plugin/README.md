# Stream Deck plugin (work in progress)

The TypeScript API client is implemented. The action-rendering prototype is in `src/plugin.ts` but is **not yet registered or packaged**; its six action classes, manifest, property inspector and images still need to be completed and validated against the installed SDK.

Settings: API base URL and API key. Polling: 60 seconds. History: 24 hours.

Do not use this as a production plugin until the backend data source and SDK packaging are verified.
